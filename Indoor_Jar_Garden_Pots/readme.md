Let's make an indoor garden! You can recycle jars from your own household, and print pots to grow herbs and salad vegetables.

### Measure
Measure the *inside* diameter of your jar, that's the most important measurement! The example measurements in the customizer will produce a pot for a standard jam jar.


### Customize
You can customize these pots to fix any sized pot.

On Makerworld:
1. click the Customize button
2. modify the parameters
3. click the Download button

On Printables or Thingiverse:
1. download the openscad file
2. modify the parameters
3. render a new design
4. export the STL


### Print
* 4 perimeters
* Enable supports
* Use standard line widths

Print with 4 perimeters, because this makes the pot watertight. (See Prusa knowledge base. https://help.prusa3d.com/article/watertight-prints_112324 )

Feel free to use the supplied profiles to get examples for your supports.

This design is optimized for a standard 0.4mm nozzle, which has a 0.45mm extrusion width. You can scale the print up or down, but it may not turn out as smooth or have the desired number of walls.
